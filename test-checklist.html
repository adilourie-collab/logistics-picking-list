מקור נתונים - פריטים

הרשימה נטענת אוטומטית מגיליון Google Sheets, ומתעדכנת מעצמה כל כמה דקות תוך כדי שימוש.
מבנה הגיליון: עמודה א׳ = שם פריט, עמודה ב׳ = כמות נדרשת, עמודה ג׳ (רשות) = סוג אריזה.
חשוב: חייבים להשתמש בקישור "פרסום לאינטרנט" (לא קישור שיתוף רגיל): בגיליון ב-Google Sheets → קובץ → שתף → פרסם לאינטרנט → בחרו את הגיליון ופורמט CSV → פרסם → העתיקו את הקישור לתוך המשתנה SHEET_CSV_URL בקוד.

מקור נתונים - עובדים ומיילים

רשימת העובדים לבחירה בתפריט נטענת אוטומטית מגיליון Google Sheets נפרד (או טאב נפרד באותו קובץ).
מבנה הגיליון: עמודה א׳ = שם העובד, עמודה ב׳ = אימייל.
יש לפרסם גם אותו לאינטרנט כ-CSV (באותו אופן) ולהעתיק את הקישור לתוך המשתנה EMPLOYEES_CSV_URL בקוד.

שימו לב: טעינה אוטומטית מהדרייב עובדת רק כשהאפליקציה מאורחת בכתובת אינטרנט אמיתית (כמו GitHub Pages), ולא כשפותחים את הקובץ ישירות מהמחשב.
